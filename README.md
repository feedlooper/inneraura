# Inner Aura — Breathwork with Gurleen Randhawa

A single-page website for Gurleen's breathwork practice in Vancouver, BC.
No build tools, no dependencies — just plain HTML, CSS, and JS.

## Upload to GitHub

Upload everything in this folder to your repo, keeping this structure:

```
index.html
images/
  hero.jpg
  portrait.jpg
  session-1.jpg
  still-1.jpg
  closing.jpg
  logo-symbol.png         (plum logo for light backgrounds)
  logo-symbol-light.png   (lilac logo for dark backgrounds)
  favicon.png
```

Enable GitHub Pages (Settings → Pages → Deploy from branch → root) and the
site is live.

## Replacing the placeholder photos

The photos in `images/` are labeled placeholders. To use Gurleen's real
photos, simply overwrite each file **keeping the exact same filename** —
no code changes needed.

| File | Where it shows | Best photo | Shape |
|---|---|---|---|
| `images/hero.jpg` | Top of homepage, arched frame | Warm, serene portrait of Gurleen | Portrait (4:5) |
| `images/portrait.jpg` | "Meet Gurleen" section | Smiling, approachable photo | Portrait (4:5) |
| `images/session-1.jpg` | Benefits section | A session or studio moment | Portrait-ish crop works |
| `images/still-1.jpg` | Benefits section | Calm detail: candles, tea, studio | Portrait-ish crop works |
| `images/closing.jpg` | Final "Book" banner background | Wide peaceful scene or Gurleen | Landscape (16:9) |

## Editing text

Everything is in `index.html`. Search for the section you want (e.g.
`Meet your facilitator`, `Sessions & offerings`) and edit the text directly.
Replace the three placeholder testimonials in the "Kind words" section with
real client quotes as they come in.
